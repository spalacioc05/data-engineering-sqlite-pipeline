# **Prueba Técnica**

## **Contexto**

Has recibido un proyecto en el cual el equipo anterior dejó un script (pipeline.py) que lee un archivo CSV local con 10,000 registros de personajes (dataset.csv) y los inserta directamente en una base de datos SQLite.

## **Tu Objetivo**

Tu misión es corregir el script y, generar dos bases de datos en SQLITE; una transaccional y a partir de esta, un modelo estrella 

## **Requerimientos Técnicos**

### **1\. Documentación y Justificación**

Crea un archivo obligatorio llamado JUSTIFICACION.md en el que narres las decisiones que has tomado en este desarrollo y las diferentes observaciones que tengas sobre el código; se espera que comentes cualquier dificultad con la que te encuentres

## **Entregables**

Envía un repositorio Git o un archivo .zip que contenga:

* Código fuente.  
* Archivo JUSTIFICACION.md.  
* Archivo db_transaccional.db
* Archivo db_estrella.db

## **Setup**

Requisitos

* Python 3.9 o superior (Descargar Python). Trabaja en un entorno virtual
* Git (Descargar Git).
* Un editor de código (recomendado: VS Code o PyCharm).
* (Opcional) Un cliente gráfico para bases de datos SQLite como DB Browser for SQLite o la extensión SQLite Viewer en VS Code.
